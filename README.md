# springboot-simple

Small Spring Boot sample API used as a starter backend project.

## Purpose
- expose a basic HTTP endpoint at `GET /api`
- keep a minimal, easy-to-read structure for demos and experiments

## Stack
- Java 17
- Spring Boot 2.7.18
- Maven (`pom.xml`)

## Build and test
```bash
mvn clean test
```

On Windows PowerShell:
```powershell
mvn clean test
```
